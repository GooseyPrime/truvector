# Lane Vector and TruVector research papers

Edition: 5 October 2026. Author: Michael Brandon Lane, InTellMe AI.

The current collection comprises WP-01 (signal direction, temporal differences, and source structure), WP-02 (reader interpretation and the TruVector decision procedure), WP-03 (research overview), and the companion validation framework. Both research websites publish identical files.

## Publication files

The editable Word documents and corresponding rendered PDFs are in `public/working-papers/`. `manifest.json` records their SHA-256 digests. The Markdown files here provide searchable text and figures; the Word documents are the authoritative typeset sources, including native mathematical notation.

## Updating the edition

Edit the Word sources and corresponding Markdown together. Export the Word files to PDF with Microsoft Word or LibreOffice using `scripts/build_working_paper_pdfs.py`; the script does not install software. Inspect every rendered page, update the publication manifest, and copy identical files to both research repositories. Check publication links and the legacy PDF endpoint after building each site.

## Interpretation

Reported study counts are attributed to the supplied research record. Worked numerical examples and diagrams are illustrations under declared assumptions. Research evaluation includes independent reproduction, controlled comparisons, calibration, source-group validation, and prospective forecasting tests.
